Scope: how shotfleet got to 0.1.7, why it is built and sold the way it is, which incidents taught which rules, and what is known to be unfinished. This chapter is a summary of `CHANGELOG.md`, `STATUS.md`, `docs/handoff.md`, `STRATEGY.md`, `ROADMAP.md`, `DISTRIBUTION.md` and `research/`; those files are the source and are dated snapshots, so read the header of a research note before trusting its numbers.

| A `NameError` at import crashed `shotfleet --version` on a Mac with no Android SDK (`SDK = find_sdk()` runs at import before `is_mac` exists) | Always run the post-deploy smoke and a clean-environment start (`env -i`) against a copy | `STATUS.md`, comment at `shotfleet.py:2376`, PR #42 |

## 11.4 Known limitations (as of this snapshot)

From `README.md` "Limits", `STATUS.md` "Unproven", `docs/compat.md`, `docs/linux.md`:

- **macOS only for `run` on iOS; Apple silicon only for the released build.** `check` also runs on Linux via Tesseract (Docker image not yet published). Android `run` on Linux has been proven once, with one emulator on a 2-core runner (PR #33); two emulators need 4 or more cores.
- **Simulators and emulators only**, never physical devices. Android phone, tablet and 7" tablet from one flow; no wearables. Android needs API 33+ images.
- **Maestro's own limits leak through**: in iOS landscape Maestro taps at portrait coordinates (shotfleet explains it, cannot fix it); Maestro 2.11.0 needed retries at 4 parallel iOS simulators on a busy Mac (9 of 19 languages once, `docs/handoff.md` "Known small things"), while 2.0.10 did not.
- **Text recognition**: Vision reads 33 languages on macOS 27, fewer on older macOS (the same Catalan screenshot is skipped on macOS 14 and judged differently on 15); Greek, Hebrew, Armenian, Georgian and most Indic scripts need Tesseract; Catalan, Croatian, Hungarian, Slovak, Slovenian are judged more weakly (`LATIN_UNLISTED`).
- **Unproven**: macOS 13 and 26.0 to 26.2 (only 26.2 in a VM), a clean Mac with an outside developer (time to first screenshot is unmeasured; "about 10 minutes" is unverifiable, claim C019), four simulators on iOS 27, a refunded key against a real paid sale, `check` on a real Paparazzi folder, the CI recipe on GitHub (the installer, `--version`, `doctor`, `check` ran on hosted runners for 0.1.1).
- **Licence**: client-side, forgeable (05 section 5.8); activations are a lifetime counter; no renewal exists.
- **Frameworks**: Flutter, Expo/React Native, Compose and MAUI were each run end to end once or twice on a sample app (`research/frameworks.md`); Unity is not planned.
- **The capacity numbers are provisional** (comments in `shotfleet.py`), and the Android emulator figure "2 cores and 3 GB each" is one data point.
