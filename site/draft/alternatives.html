What each tool does

shotfleet

Rewrites one English Maestro flow for every language your app ships using the app's own compiled strings, runs the flow in parallel on simulators and emulators, checks each screenshot (language, copies, missing, store size rules), and exports to fastlane's folders.

Setup: one command, a two-line config, a Maestro flow in English. Proven on CrossfitTracker (18 languages, iOS 9 min / Android 15 min) and Kuokka (Compose, iPhone + 13" iPad).

fastlane snapshot / screengrab

The standard: UI-test code (XCUITest, Espresso) that taps buttons and takes screenshots, run once per language. You add a test target and accessibility identifiers to your app, and iOS and Android need separate code. Free, huge community, works in CI.

If you already have UI tests that run in every language, you may not need shotfleet. If you don't want test code in your app, or want one flow for both platforms and a check of the results, that is the gap shotfleet fills; fastlane still handles upload and framing.

simshot

Free, MIT-licensed, iOS only. A bash script that launches the app in each language with launch arguments and takes screenshots. Needs about 3 lines added to your app. Very new: 0 stars when checked.

ButterKit

Captures from the iOS Simulator with one click, applies device frames and captions, translates marketing text with AI, uploads to App Store Connect. Its page does not say it re-captures the app in each language. Free tier with watermarks; Pro $99 one-time (was $149), includes 5 Macs and free updates. Supporter tier $39/yr. Limited Android support.

How to use it with shotfleet: Run shotfleet to get the raw localized screenshots in fastlane's folders. Point ButterKit at those same folders, add frames and captions, and upload. shotfleet's check tells you whether the language inside the app really is the one on the listing.

AppScreens

Web editor: upload screenshots (or paste mockups from Figma), add device frames, text, backgrounds. iOS and Android. Pro $99/yr (10 languages), Scale $180/yr (80+ languages). Doesn't capture from the app; makes marketing images from what you upload.

When you should NOT buy shotfleet

If you use any of these, start there first

  • You don't ship localized screenshots. fastlane snapshot or simshot (both free) will do the job.
  • You already have a fastlane UI-test setup working well and don't mind multiple tests per language.
  • You want frames, captions, or store upload. ButterKit and AppScreens specialize in that; shotfleet doesn't.
  • Your app is Flutter or React Native. Shotfleet can read your translation files, but this has not been tested on a real app yet.
  • You don't have a Mac or Maestro. shotfleet runs on macOS only and requires Maestro to be installed.

The story

I ship a workout app in 18 languages. My Maestro screenshot flow taps English buttons, so my first "localized" screenshots were the English set copied into every language. Fixing that properly meant a one-off script.

So I wrote shotfleet: one English flow, every language, both platforms, checked. On the first full run, I found that the onboarding button was unreachable in Japanese, Korean, Chinese and Arabic on small phones: taller text, no scrolling. It was a small fix in my app. Nobody had noticed because English screenshots fit fine.

ButterKit, AppScreens and fastlane do different things: make framing, make mockups, run UI tests. shotfleet makes sure the raw screenshots inside your app are actually in the right language.
