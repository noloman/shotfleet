# SEO and AI-search audit of shotfleet.com, 2026-10-06

Follow-up to `research/seo-audit.md` (2026-10-02/03). That file has the full method, the Redirect Rule recipe and the keyword plan for articles 1 to 8; this one says what changed since, what is still wrong, and what branch `claude/seo-improvements` fixed.

Two things were audited:

- **The live site**, https://shotfleet.com, fetched with curl on 2026-10-06 (version 0.1.4 of the site: no /whats-new yet).
- **main's version**, origin/main 1c91f66, `site/public/`. It has /whats-new and the newer copy, and goes live with 0.1.5.

Method: the `marketing:seo-audit` checklist (crawlability, on-page, content gaps, technical, competitors) and the `ai-seo` checklist (extractability, llms.txt, bot access, schema). No `schema` skill is installed, so the structured data follows schema.org and Google's documented rules from memory, marked as such. No SEO connector (Ahrefs, Semrush, Search Console) is authorized: **there is no search-volume, difficulty, ranking or impression number in this file.** Keyword evidence is what a web search returned on 2026-10-06; that search tool is not Google.

## 4. Structured data

Before: one SoftwareApplication block on `/` (offers 0, 29, 49 USD, InStock, author, softwareRequirements). After:

| Page | Blocks |
|---|---|
| `/` | `WebSite` (name "shotfleet", url, publisher; helps Google pick the site name) + the existing `SoftwareApplication`, unchanged |
| `/docs` | `@graph`: `TechArticle` (dateModified = the page's "Last checked" date, about the SoftwareApplication's `@id`), `BreadcrumbList` (Home > Docs), `FAQPage` (the 7 visible questions, same text) |
| `/alternatives`, `/demo`, `/whats-new` | `BreadcrumbList` (Home > page) |
| Guides (generator) | `Article` (unchanged, honest fields only, as tested) + `BreadcrumbList` (Home > Guides > title) |

Not added, on purpose: `aggregateRating`, `review`, `softwareVersion`, `downloadUrl` (tested as banned on `/`), `HowTo` (Google dropped HowTo rich results; from memory), FAQPage on `/` (tested as banned there; the FAQ lives on /docs). Google shows FAQ rich results only for government and health sites since 2023 (from memory), so the FAQPage is for other engines and for meaning, not for a rich result.

Validation: every JSON-LD block on every page and draft parses with `json.loads` (16 blocks); a new test, `JsonLd.test_every_json_ld_block_on_every_page_parses_and_uses_schema_org`, keeps it so, and `JsonLd.test_the_docs_faq_markup_is_the_visible_faq_and_its_date_is_the_last_checked_date` keeps the FAQ markup equal to the visible questions and the TechArticle date equal to the "Last checked" line. The blocks are data, so the CSP (`script-src 'self'`) needs no change (verified in the earlier audit). Not run: Google's Rich Results Test and validator.schema.org (web forms; submitting the site is the owner's call).

## 5. Open Graph, Twitter, performance, images, links

- **Social tags:** every page now has og:title, description, image (1200x630, absolute), image width, height and alt, url, type, site_name, locale, and `twitter:card=summary_large_image` (Twitter falls back to og for the rest). One shared `og.jpg` for all pages; per-page images are a later nice-to-have.
- **Page weight (live, brotli):** home HTML 7.4 KB; site.css about 7 KB; five small scripts about 3.5 KB; Geist Mono latin 22.6 KB (preloaded); three eager screenshots above the fold, about 117 KB; the rest lazy. Full-size images (1.4 MB) load only on click. /demo: nine clips with `preload="none"`, but their nine WebP posters (22 to 62 KB each, about 330 KB) load with the page; acceptable, could be lazy-loaded later with a small script if PageSpeed complains.
- **CLS:** every `<img>` has width and height; every `<video>` has `width="1280" height="720"` and CSS `height: auto`, so the box is reserved before the poster loads: no layout shift from the clips. The only shift source was the late web font on pages without the preload; fixed.
- **Image formats:** screenshots are JPEG (360 px wide thumbnails), posters WebP. WebP for the thumbnails would save some bytes; low priority at this weight (not measured).
- **Alt text:** all images have descriptive alt; the zoom dialog's image starts empty on purpose and gets its alt from the clicked image.
- **Internal links:** every page links Home, Docs, What's new, Alternatives, Terms, Privacy in the footer and See it work in the nav. Added: /alternatives links its "run shotfleet check" sentence to `/docs#check` and points to the clips on /demo; the /docs FAQ links /alternatives, /#price, #check and #strings. The home page already links deep into /alternatives (#fastlane, #butterkit, #appscreens).
- **Core Web Vitals:** not measured (no PageSpeed run today). The earlier local Chromium run put LCP at the hero paragraph, about 65 ms.

## 10. What still needs the owner

1. **Search Console and Bing Webmaster Tools**: verify the domain (DNS TXT at Cloudflare), submit `https://shotfleet.com/sitemap.xml`, request indexing for `/`, `/docs`, `/alternatives`. Bing feeds Copilot and other assistants. Two to four weeks of data before any keyword decision.
2. **HSTS** in Cloudflare (finding 10) and a look at Cloudflare's AI bot settings (Block AI bots off, managed robots.txt off).
3. **Publish the guides**, starting with article 2 (all items ticked), after `wrangler dev` confirms nested routing; then tick and publish 1, 3, 5, 6. Add them to llms.txt in the same commit (the generator adds the sitemap entries).
4. **Directory listings** (backlinks and the places assistants look): AlternativeTo (as an alternative to fastlane snapshot), Product Hunt, Hacker News Show HN (kit already drafted), SaaSHub, the Maestro community and awesome-lists (awesome-ios, awesome-android tooling, awesome-flutter), Homebrew tap already exists. The `directory-submissions` skill can plan this; submitting is the owner's or coordinator's job.
5. **Real reviews** on a third-party site (AlternativeTo, Product Hunt) before any rating markup is possible.
6. **A cadence**: one guide a week after launch (MARKETING.md phase 2), each with real output and a date; refresh /alternatives prices every quarter (its "Checked on" date is 2026-10-02).
7. **Answers where people ask**: the Expo forum question, fastlane screengrab locale threads, Maestro's Slack and GitHub discussions on locales; one honest answer with a link to the matching guide, by Manu, not automated.
