`test_json_multi_report.py:31`, `test_release_candidate.py:164`, `test_cli_claims.py:256` (MCP check), `test_shotfleet.py` 979, 1254, 1278, 1381, 1607.

Cheap next steps (proposals):
1. Make `fake_vision()` the default for every test that is not about Vision (a `setUpModule` in each module that calls `cmd_check`, or an env var the helper reads), and keep one explicit real-Vision smoke test. Expected: suite under ~60 s, stable.
2. Parallel by module with the stdlib: `ls tests/test_*.py | sed 's|/|.|;s|\.py$||' | xargs -P 4 -n 1 python3 -m unittest` (a 10-line `tools/test-parallel.sh` that collects exit codes). CPU is low (waits), so 4-wide should cut wall time roughly to the slowest module. Risk: `test_selftest` compares the set of `/tmp/shotfleet-selftest.*` before and after, which a parallel module could disturb; give it its own `TMPDIR`.
3. Fixed sleeps worth shortening: `test_fixture_e2e` (9.5 s, 5.0 s), `test_shotfleet` warm-up (4.3 s), `Config...cli_exits_2` (6.3 s, spawns Python), `FreeTier` (5.9 s). Small: ~30 s together.
